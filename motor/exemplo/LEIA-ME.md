# Exemplo: Marina, enfermeira (persona fictícia)

Esta pasta mostra como fica a `eu/` de uma pessoa depois da entrevista, de um
post publicado e de um CV para uma vaga. Serve para quem mantém o kit ver o
formato de cada arquivo preenchido, e como gabarito dos testes.

A Marina não existe. Os hospitais, a faculdade, o email, o telefone e o link
são inventados.

**Nenhuma skill lê esta pasta.** Um fato daqui não pode acabar no perfil de
uma pessoa real. Para gerar o CV dela: `python3 motor/cv/gerar.py --eu motor/exemplo base-pt`.
